01

The problem we solve

UK businesses and households are routinely overbilled on energy, and almost nobody checks. Bills arrive as PDFs and phone photos in dozens of supplier-specific layouts, burying the figures that matter — MPAN, unit rates, standing charges, meter reads and contract dates. Estimated reads overcharge, duplicate line items slip through, totals quietly fail to add up, and fixed contracts roll onto expensive out-of-contract rates because renewal dates go unnoticed. Checking this by hand across a portfolio is slow and error-prone. Voltscope reads each bill, validates every figure, and flags exactly what is wrong — deterministically, in seconds.

02

Key features

Structured extraction — Every field from any UK electricity or gas bill: supplier, MPAN/MPRN, tariffs, unit rates, standing charges, meter reads, charges and totals.
Deterministic validation — Ten registered checks, each finding carrying a severity, category and a plain-English recommendation.
Human-in-the-loop review — Web interface to review extracted fields beside findings, correct anything, and re-validate instantly on save.
Portfolio intelligence — Renewal alerts, estimated-read reports, duplicate-charge detection with quantified overcharge, spend summaries and supplier comparison.
Multi-page & HEIC — Combine several photos into one bill; iPhone HEIC handled automatically alongside PDF, PNG, JPG, WEBP and GIF.
High-unit-rate flags — Tariffs above a portfolio-relative baseline surfaced automatically, adapting as the portfolio grows.
Export — JSON, a four-sheet Excel workbook and CSV for auditors, accountants and spreadsheets.
REST API & audit trail — Full OpenAPI/Swagger docs, API-key auth, SQLite persistence and processing history.

Technical architecture

Extraction — Anthropic Claude API · vision over PDF & images · conservative JSON schema
Backend — FastAPI · Uvicorn · Pydantic v2
Validation — Registry of deterministic checks · typed Finding model
Intelligence — Pure-Python analytics · zero LLM calls
Data layer — SQLite · lossless JSON + queryable columns · history
Frontend — Dependency-free vanilla JavaScript · single file
Export — openpyxl (Excel) · CSV · JSON
Auth — API-key (X-API-Key) · OpenAPI security scheme
Testing — 50 tests · golden fixtures · pytest
Deployment — Docker · Render blueprint · $PORT-ready
